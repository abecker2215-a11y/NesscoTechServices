# Azure Deployment Plan: Nessco Tech Services (msp-website)

## Project Overview
- **App Name**: msp-website (Nessco Tech Services)
- **Framework**: Next.js 16.5.0-canary.3 (App Router, Turbopack)
- **Runtime**: Node.js 20+ (React 19, TypeScript)
- **Database**: PostgreSQL (Prisma ORM) — required for Client Portal
- **Auth**: NextAuth.js v5 (credentials + email magic links)
- **Key Features**: Marketing site, AI chat (Azure OpenAI), Client Portal, PSA webhooks, Calculators, Blog/Guides

---

## Phase 1: Analysis & Requirements

### Workspace Mode
**MODIFY** — Existing codebase with all features implemented; needs Azure infrastructure + deployment config.

### Components Identified
| Component | Type | Azure Target |
|-----------|------|--------------|
| Next.js App (marketing + portal + APIs) | Web App (containerized) | Azure Container Apps |
| PostgreSQL (Prisma) | Database | Azure Database for PostgreSQL Flexible Server |
| Secrets (NEXTAUTH_SECRET, API keys, DB connection) | Secret Store | Azure Key Vault |
| Container Images | Registry | Azure Container Registry |
| Static Assets (images, sitemap) | Static Files | Served by Next.js / Azure Storage (optional) |
| Custom Domain (nesscotech.com) | DNS + TLS | Azure Front Door + Custom Domain |
| Observability | Logs/Metrics | Azure Monitor + Application Insights |

### Scale & Budget
- **Traffic**: Small business marketing site + client portal (~100s visits/day, ~10s portal users)
- **Budget**: Cost-optimized (~$50-150/mo target)
- **Region**: East US 2 (or user-preferred)

### Compliance
- No special compliance requirements (standard business data)
- HTTPS enforced, secrets in Key Vault

---

## Phase 2: Recipe Selection

**Chosen Recipe**: **AZD (Azure Developer CLI)** with Bicep
- Uses `azure.yaml` + `infra/*.bicep` for infrastructure-as-code
- Supports Container Apps + PostgreSQL + Key Vault + ACR
- Single command deploy: `azd up`
- Built-in validation via `azure-validate` skill

---

## Phase 3: Architecture Plan

### Azure Services
| Service | SKU/Tier | Purpose |
|---------|----------|---------|
| Container Apps Environment | Consumption | Host Next.js container |
| Container App | CPU: 0.5, Mem: 1Gi, Min: 0, Max: 3 | App workload |
| PostgreSQL Flexible Server | Burstable B1ms (1 vCore, 2 GiB) | Primary database |
| Azure Key Vault | Standard | Secrets management |
| Azure Container Registry | Basic | Docker image storage |
| Azure Front Door | Standard | Custom domain, TLS, WAF |
| Application Insights | Workspace-based | Telemetry |
| Log Analytics Workspace | Pay-as-you-go | Logs |

### Networking
- Container Apps: Internal ingress + Front Door external
- PostgreSQL: Private access (VNet integration) or public with firewall + Key Vault
- ACR: Private endpoint or public with admin disabled

### Secrets Management (Key Vault)
| Secret | Source |
|--------|--------|
| NEXTAUTH_SECRET | Generated (openssl rand -base64 32) |
| DATABASE_URL | Constructed from PostgreSQL connection string |
| RESEND_API_KEY | User-provided |
| AZURE_OPENAI_API_KEY | User-provided (optional) |
| AZURE_OPENAI_ENDPOINT | User-provided (optional) |
| PSA webhook secrets | User-provided |

### CI/CD
- GitHub Actions workflow (generated by azd) for build + deploy on push to main
- Or manual `azd deploy` from Windows PC
